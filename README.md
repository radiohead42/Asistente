# Asistente

Asistente desarrollado con **Python** como proyecto de exploración de automatización, interacción por consola y procesamiento de comandos.

## Descripción

El proyecto contiene un asistente programado en Python que recibe instrucciones del usuario y ejecuta respuestas o acciones definidas por la aplicación.

## Tecnologías

- Python
- Programación orientada a funciones
- Automatización de tareas

## Requisitos

- Python 3 instalado.
- Git.

## Instalación y ejecución

```bash
git clone https://github.com/radiohead42/Asistente.git
cd Asistente
python asistente.py
```

En algunos sistemas puede ser necesario utilizar `python3` en lugar de `python`.

## Objetivos del proyecto

- Practicar el manejo de entradas y salidas en Python.
- Explorar la automatización de tareas.
- Crear una base extensible para incorporar nuevas funciones.

## Estado

Proyecto experimental y de aprendizaje con Python.
